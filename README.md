# NewsHub
NewsHub — це вебзастосунок онлайн-газети, розроблений для перегляду, пошуку та персоналізованого отримання новин різної тематики.

Система надає користувачам можливість ознайомлюватися з актуальними публікаціями, взаємодіяти з новинними матеріалами та налаштовувати інформаційний простір відповідно до власних інтересів. Також передбачено адміністративну панель для керування вмістом вебсайту.

Основні можливості
- Перегляд новин за тематичними категоріями.
- Пошук статей за ключовими словами та фільтрація за категоріями.
- Реєстрація, авторизація та особистий профіль користувача.
- Додавання коментарів і вподобань до публікацій.
- Збереження статей для подальшого перегляду.
- Вибір улюблених категорій та отримання персоналізованих рекомендацій.
- Підписка на авторів і сповіщення про їхні нові публікації.
- Отримання сповіщень про термінові новини та дайджести.
- Перегляд доступних тарифних планів.
- Доступ до ексклюзивних матеріалів відповідно до тарифного плану.
- Відображення рекламних матеріалів.
- Адміністративна панель для додавання, редагування та видалення новин.
- Можливість позначати публікації як термінові або ексклюзивні та формувати дайджести.

Структура проєкту

Основна частина програмного коду розміщена в директорії app/. Вона містить модулі застосунку, HTML-шаблони, статичні файли та інші компоненти, необхідні для роботи системи.

Файл run.py використовується для запуску вебзастосунку, а requirements.txt містить перелік необхідних Python-бібліотек.
Встановлення та запуск
Для локального запуску проєкту необхідно мати встановлений Python та Git.

1. Клонування репозиторію
git clone <URL_репозиторію>
2. Перехід до директорії проєкту
cd coursework_documentation
3. Створення віртуального середовища
python -m venv .venv
4. Активація віртуального середовища (Windows PowerShell)
.venv\Scripts\Activate.ps1
5. Встановлення необхідних залежностей
pip install -r requirements.txt
6. Запуск вебзастосунку
python run.py
Після успішного запуску вебзастосунок буде доступний у браузері за адресою:
http://127.0.0.1:5000/
